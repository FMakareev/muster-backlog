## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
main.go embeds `all:frontend/dist`, and that directory is generated by the frontend build and gitignored. On a fresh checkout it does not exist, so every Go command that compiles package main fails at the embed: 'pattern all:frontend/dist: no matching files found'. CI died there in the lint step.

It is not a CI-only problem. The same clone cannot run `go test -tags gtk3 ./...`, which CONTRIBUTING tells a contributor to run before pushing, and the pre-push hook fails for the same reason. It passes here only because a previous build left the directory behind.
<!-- SECTION:DESCRIPTION:END -->

## Implementation Plan

<!-- SECTION:PLAN:BEGIN -->
1. Reproduce: with frontend/dist removed, `go build` fails at the embed; an empty directory fails too ('contains no embeddable files'), so the placeholder has to be a file.
2. Commit frontend/dist/.gitkeep and add the .gitignore exception that keeps the built assets ignored while tracking the placeholder.
3. Do not make CI build the frontend before linting: that fixes only CI, leaves the fresh clone and the pre-push hook broken, and pays a frontend build on every lint.
4. Add a test asserting every go:embed pattern resolves to something git tracks.
5. Verify in a fresh clone: lint and test with no build history, then a real build, and confirm the built binary carries the real assets rather than the placeholder.
